Product Label ZPL 2x1
=====================

Este módulo permite generar etiquetas de productos en formato ZPL 2x1 pulgadas 
para Odoo 18 Community. Incluye soporte para etiquetas con y sin precio, 
descarga de archivos ZPL listos para envío a impresoras Zebra y 
uso del wizard estándar de productos.

Documentación completa
======================
