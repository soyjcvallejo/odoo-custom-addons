Uso del módulo
==============

1. Seleccionar uno o varios productos desde el inventario.
2. Abrir el wizard “Imprimir etiquetas”.
3. Elegir el formato de impresión:
   - ZPL 2x1 → etiqueta básica.
   - ZPL 2x1 con precio → etiqueta con precio incluido.
4. Descargar el archivo ZPL generado.
5. Enviar el archivo a la impresora compatible Zebra.
